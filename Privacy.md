1. Information We Collect
To Discovery, Sage (“the Bot”) does not collect or store any personal data.

Specifically, the Bot does not store:
Usernames
User IDs
Server/Guild IDs
Message content
IP addresses
Emails
Any personally identifiable information
The only information processed is what Discord automatically provides to execute commands, such as the user ID of the command author. This information is used ephemerally and is never logged or saved.

2. What the Bot Stores

The Bot only stores publicly available Deepwoken reference data, such as:
Talents
Mantras
Outfits
Weapons
Oaths
Enchants
Status effects
No stored data is linked to any Discord user or server.

3. How We Use Information
Any temporary data received from Discord is used solely to execute commands and provide bot functionality.
The Bot does not analyze, sell, or share this data.

4. Data Sharing
We do not share any user information with third parties.
We do not sell data.
We do not transfer user information.
Since the Bot does not store personal data, none can be shared.

5. Data Deletion
Because the Bot does not store personal data, there is nothing to delete.
If you have questions or concerns, you may contact us.

6. Security
Although the Bot stores no user data, we still take reasonable measures to secure its systems and database. However, no system is completely free from risk.
